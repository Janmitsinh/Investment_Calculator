# Investment Calculator
This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 18.0.0-next.2.

## Project Description

The Investment Calculator is a web application built using Angular that helps users calculate and visualize their investment growth over time based on different parameters such as principal amount, interest rate, and duration. It is designed to be user-friendly and provides a clear graphical representation of the results.

## Features

Real-time Calculations: Inputs are dynamically processed, and results are updated instantly.
Graphical Visualization: Displays investment growth using visually appealing charts.
Customizable Parameters: Users can set various parameters like principal amount, interest rate, and investment duration.
Responsive Design: Optimized for use on both desktop and mobile devices.
Built with Angular: Leverages Angular's powerful features for a seamless user experience.
